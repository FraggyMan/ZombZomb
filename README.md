# ZombZomb

## How to get the game
To get the game, you can find it on Penguinmod, or soon on github.

### How to play it on Penguinmod:
To play it on Penguinmod, use this link: [The game](https://penguinmod.com/search?q=ZombZomb)

### How to play it on GitHub:
The GitHub repository is not set up yet, but it will be on the repistory page.

## System Requirements
There are no official system requirements, but there are a few things we do recommend.

### Recommendations:
* **Windows 7 or newer**. Mobile is not supported, unless you have an external keyboard and mouse.
* A web browser like Chrome, Edge, or Firefox. **SAFARI IS NOT SUPPORTED**. The web browser must also have enabled JavaScript.
* A mouse and keyboard for gameplay. Touch is not supported.

## Starting the game

### Loading:
To start the game, press the blue flag on Penguinmod and on GitHub. When the game starts, it may need to download a few resources. These resources are not cached so every time you quit out of your browser and go back in, you will have to redownload the resources again. Though, depending on your internet speed, it most likely should take under a minute.

### Jumping in:
When you finally load into the game, you should get a menu that looks somewhat like this:
![Main Menu Diagram](https://raw.githubusercontent.com/FraggyMan/ZombZomb/refs/heads/main/help/ZombZomb%20Main%20Menu.png)

### What everything does:

* Levels: A level you can select by clicking on it. Scroll up or down with the mouse scroll wheel to see all the levels.
* Previous and Next Page: Bring you to the previous or next page of levels. There are 5 pages. 4 world pages, and a minigame page.
* Level Difficulty: A label to show how difficult the level is going to be.
* Game Difficulty: Changes how hard the game will be. Can be from 1 to 6. 1 for Easy, 6 for Extreme.

### Getting into a level:
To get into a level, just click on it with the mouse. The level can be one of 4 worlds:

* Plains (World 1)
* Woods (World 2)
* Cave (World 3)
* City (World 4)

### How to play the game:
To play the game, you aim your player at zombies, and click to shoot. To move around, use the arrow keys. Defeat every zombie in the level and don't die to win.

### Using the UI:
When you are in a level, the UI should look like this:
![In-Game UI](https://raw.githubusercontent.com/FraggyMan/ZombZomb/refs/heads/main/help/ZombZomb%20In-Game%20UI.png)

### What everything does:

* Player: Your player that you move around and aim with your mouse pointer.
* Health: Your player's health points. It is set to different values depending on the world or level.
* Level: The level name. If it is a minigame, will say the name. If it is a regular level, it will say the level number. (World-Level)
* Progress: How far you are in the level. The more full, the further you are in the level.
* FPS: The frames per second. Maximum is set to 60 for best performance.
